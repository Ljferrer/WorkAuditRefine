# WAR — Context

The router for WAR (Work · Audit · Refine). Read the one entry that fits your task, then
stop. The ubiquitous language lives in GLOSSARY.md: its contents list links each section.

## Roles

- Lead: when you run a /war phase, read skills/war/SKILL.md
- worker: when you build one task, read agents/war-worker.md
- auditor: when you judge a task diff, read agents/war-auditor.md
- refiner: when you merge, land or provision, read agents/war-refiner.md
- servitor: when you record phase lessons, read agents/war-servitor.md
