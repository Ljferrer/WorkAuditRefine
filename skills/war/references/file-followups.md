# File-followups dispatch — filing procedure

Read when dispatched a `file-followups` run (pointer on `agents/war-refiner.md` § File-followups
dispatch). Evicted from that card under its prompt-surface byte budget (ADR 0042); per ADR 0047
adjudication O(1) this file is best-effort enrichment, never the sole carrier — the dispatched
prompt carries the same instructions verbatim, and the card keeps the never-decline rule and the
`FOLLOWUP_FILING_RESULT` return shape inline (§ Return).

**Preflight first** (ADR 0026): run the dispatched `gh-preflight.sh` line before any gh write; exit 2 or 3 ⇒ return what you have, file **nothing**. **Dedup first**: `gh issue list --label war-followup --state open` — a row matching an open issue (exact title, or same file + root cause) gets a **corroboration comment** there, never a new issue; reuse its number. Cluster remaining rows by file + root cause (rows carry file/line/`seats`); file one `war-followup` issue per **cluster** — members share one issue number. Return ONLY `{ filed: [{ n, issue }], clusters: [{ ordinals, issue }] }` — a fail-open evidence return (unmatched entries stay `issue: null`; the Checkpoint floor catches them; `clusters` covers every ordinal exactly once), never a `MergeResult`. EACH filed issue body ends with an `## Evidence artifacts` section carrying, per member row, the pinned sha, the file path (with line when present), the raising seat lenses, and the audit round — every value copied verbatim from the candidate rows (`unrecorded` stays `unrecorded`, never invented); on the dedup arm the same lines ride the corroboration comment instead.

**Ruled-ask filing parity (#1550, ADR 0013 amendment 2026-08-25).** This dispatch consumes the engine's consolidated `minorsFiled` rows ONLY — a parked `asks[]` record is structurally excluded: an **unruled ask is never filed**, by this dispatch or any other route. Ruled asks — parked decision-shaped questions the operator ruled at the Checkpoint strike-list gate — file **Lead-side** (SKILL.md § Checkpoint), with **filing parity** to the rows above: the same dedup-first discipline (an open `war-followup` match — engine-filed rows included — takes a corroboration comment, never a duplicate issue), and the same `## Evidence artifacts` section per filed issue (pinned sha, file path with line when present, raising seat lenses, audit round — every value verbatim, `unrecorded` stays `unrecorded`), plus the ruling itself: the question, the fork, and the operator's ruling with its moment.
