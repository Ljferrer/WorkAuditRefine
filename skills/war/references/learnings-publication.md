## Promotion steps (Gate 2 step 2)

   - Provision a transient publication worktree on the working branch: `bash ${CLAUDE_PLUGIN_ROOT}/skills/war/assets/provision-worktrees.sh ensure-publication-worktree <worktreeRoot>/<runId>/p<N>-publication <working>`.
   - **Compare before the copy.** For each selected file whose slug already has a repo file, run `diff <repo-file> <local-file>`. When it prints a `<` line, the repo copy carries text the local copy lacks, so the local copy is **stale-local**: it is **not** promoted, stays in the local root, and is reported beside the lint-flagged files — never dropped. The Lead folds the repo-only text into the local copy by hand and re-runs.
   - Copy the rest of the selection into `<pub>/docs/learnings/` (honoring a non-null `overrides.learningsTarget` as the repo-root path). A same-slug repo file that passed the compare is **overwritten** — overwrite-on-promote is the recurrence-update mechanism.
   - Run `node …/war-memory.mjs lint` over that directory in the publication worktree. Publication **fails closed**: a lint-flagged file is **not** promoted, stays in the local root, and is reported — never dropped; if every file is flagged or stale-local ⇒ no commit, `remove-publication-worktree`, done.
   - Commit `docs(learnings): phase N` in the publication worktree, **plus the CLAUDE.md pointer duty** (below, same commit).
   - **Pre-push staged-file check (never skip).** **Refresh first:** `git fetch origin <working>` in the publication worktree — remote-tracking refs are only as fresh as the last fetch, and an unrefreshed left boundary would condemn (and revert) commits origin already has. On a non-zero fetch exit: do not probe, do not push — escalate, leaving the worktree in place for inspection (the flow's standing posture). Before pushing, enumerate **every unpushed commit** and its file set in the publication worktree — `git log --name-only --format='commit %H' '@{upstream}'..HEAD` — and confirm every path in every listed commit is under the resolved promotion destination (default `docs/learnings/`, or a non-null `overrides.learningsTarget`) or is `CLAUDE.md` (the pointer duty). **One deterministic fallback, not a choice:** when `git rev-parse --abbrev-ref '@{upstream}'` fails (the transient publication worktree has no upstream configured), probe `git log --name-only --format='commit %H' origin/<working>..HEAD` — the working branch's remote counterpart, the fork point against the `ensure-origin` push target. **ANY** commit in the probed range carrying any other path is **condemned** — the whole range, never the tip alone: it means stale tracked files were staged from a stale checkout (the recorded incident staged stale version slots and silently reverted a landed release while lock-step stayed green) — do **not** push. **Neutralized-pair exemption:** a commit is *not* condemned when a later commit **in the same range** reverts it — linked by git's own `This reverts commit <sha>.` body token — and that reverting commit is likewise exempt, its file set being those same escaping paths by construction. The pinned probe's `--format` suppresses commit bodies, so establishing that link takes one extra read: `git log --format='%H%n%b'` over the same range shows each candidate's body. **Undo routing.** When the condemned commit **is** `HEAD` **and** is either the only one condemned **or** the just-authored `docs(learnings): phase N` commit among several condemned (the shield below routes that case here first), undo it in the publication worktree: `git reset --hard HEAD~1` — a commit provably **unpushed** (origin has never seen it). This is the **sanctioned exception to the no-`reset --hard` shared-branch doctrine, scoped to an unpushed commit in the transient Lead-owned publication worktree** — a chosen carve-out, not a doctrine conflict; any uncommitted state there is discarded by design, since the worktree exists only for this commit and is removed next step. Only then run `remove-publication-worktree`, re-provision, and re-commit exactly as today. When the condemned commit is **not** `HEAD`, or **more than one** commit is condemned, never rewind — `git revert` each condemned commit instead (never rewind published or built-upon history) — with ONE shield: the just-authored `docs(learnings): phase N` commit is itself **never reverted** (reverting it would unpublish the promotion while the flow marches on to the push and the marker stamp below — a successful push that falsely claims publication, the exact outcome ADR 0022 §(I) rejects). When that just-authored docs commit is among the condemned, it takes the `reset --hard HEAD~1` carve-out above **first** (it sits at `HEAD`, provably unpushed), the revert routing then applies only to the condemned commits beneath it, and the pass ends in the same `remove-publication-worktree` + re-provision + re-commit. A conflicted revert is `git revert --abort` + escalate, leaving the worktree in place for inspection (the flow's standing push-failure posture). **The undo pass terminates — push or escalate, never a loop:** re-probe the range afterwards, reading commit bodies for the exemption as above; the exemption makes each neutralized pair clean, so a clean re-probe proceeds to the `ensure-origin` push below with the promotion genuinely in the pushed range (the docs commit survived untouched, or was freshly re-committed after a reset). **Bounded, both arms:** if the re-committed docs commit is condemned again, do not loop; escalate (the staleness is not worktree-local); likewise a re-probe that condemns any commit again after a completed revert pass — beyond the exemption's neutralized pairs — escalates rather than re-entering this routing.
   - Push via `bash …/provision-worktrees.sh ensure-origin <working>` (push-first CAS, never force). On **any** failure (deliberately classification-free): fetch and replay the docs commit onto the fetched tip in the publication worktree, **retry once, then escalate** — leave the worktree in place for inspection (never-lose-unmerged-commits; the Setup/Gate-2 heal scan is the standing recovery at the next entry).
   - `remove-publication-worktree <pub>` (fail loud).
   - **Only after the successful push**, stamp each promoted local original with the marker — nested under `metadata:`, exactly `metadata.promoted: <workingBranch>@phase-<N>` — and **never delete it**. Promotion is a copy-with-marker: the local row stays visible to `render-index`/prefetch/`/lessons-learned` until the campaign PR merges; the marked copy is retired by a future `/lessons-learned` pass once the merge is confirmed.
