## The sweep

**Retired-token sweep (every landed phase; #930).** At each landed phase close — **including a phase you completed manually** via the §4.3 escalation-completion recipe (held phases get no record line) — judge **from the landed phase diff** (mandatory input: working tip before the phase → landed tip — ace/fix-round commits carry retirements no plan prose names), informed by the plan slice / Commander's Intent: did this phase **retire, rename, or consolidate a land, merge, or escalation mechanism** (a command, script subcommand, procedure step, or status token that prior lesson prose could cite as a recipe)? **Never plan-declared** — a plan field would reopen the gap whenever the plan forgets, the exact failure mode being fixed. No trigger ⇒ write the `retired-token sweep: n/a` record line and stop. On a trigger, **derive the tokens**: the *old* mechanism's literal command fragments, per-refactor and Lead-derived (no hardcoded list), **anchored multi-token pairs preferred** (e.g. `git push` + `--force-with-lease`) to cut still-live false hits. Then run **two nets over the hot corpus only**: (1) a literal grep of both hot roots — the repo learnings root (`docs/learnings/`, or a non-null `overrides.learningsTarget`) read **at the just-landed tip** (`git fetch origin <working>`, then `git grep <token> origin/<working> -- docs/learnings/` with `archive/` **excluded** — never the possibly-lagging session checkout, the servitor-verify staleness family), and the Setup-resolved local root (filesystem grep, no git; `archive/` excluded). **This grep is a completeness floor, not a ceiling:** (2) after it, run `node ${CLAUDE_PLUGIN_ROOT}/skills/_shared/war-memory.mjs query '<mechanism terms>' --local <Setup-resolved local root> --repo <resolved repo root>` (**both flags load-bearing** — the CLI has no cwd fallback and a flagless query silently walks an *empty corpus*; add `--repo` only when the repo root resolved, the prefetch paragraph's flag discipline), **discard any `archive/` rows it returns** (cold lessons are `/lessons-learned` territory — both nets stay hot-only), then **hand-scan, bounded**: the query's returned rows plus any lesson whose title/keywords name the mechanism (order ~6–12 lessons), each same-meaning straggler listed as a survey-derived correction; adjudicate any hit inside a lesson **this phase itself rewrote** against the **tip-true** content (`git show origin/<working>:<path>`). **Adjudicate each hit** (no allowlist file — exemption is a judgment call): **load-bearing** = recipe-position (an imperative step the reader is told to run now) **and** the recipe as written is no longer the sanctioned path; **exempt (counted, K)** = narration-position (past-tense, negated, or teaching mention) **or** still-live-in-context (the token is retired only for a specific procedure and this usage is a different, legitimate one — e.g. raw `git push` in a lesson about PR-branch pushes). **Routing.** Repo-root **load-bearing** hits → **one consolidated issue per triggering phase**, labeled exactly `war-followup`, filed **inside the same preflighted per-phase gh-write batch** above (never a bare `gh` call) and **dedup-checked first** (`gh issue list --label war-followup --state open`; an open retired-token issue naming the same mechanism gets this phase's hits as a comment, never a duplicate) — each hit as lesson slug + the stale recipe fragment (quoted only from the already-public, redaction-linted repo lesson — never a local one) + the replacing mechanism, plus the close condition (*close when each named lesson's recipe is corrected; the correcting change cites this issue*); **no tip-dependent claims (SHAs) in the body.** Repo-root **exempt** hits are named (slug + one-line reason) in the phase report so K is auditable. **Local-root hits: counts only on every gh-mirrored surface** (the record line, and the phase report that mirrors onto the public epic issue); slugs + one-line adjudications go to the **uncommitted ledger notes only** (`.claude/war/` is git-excluded, never gh-mirrored), where the next `/lessons-learned` pass reads them — local body text and local paths appear **nowhere** off the local machine. **No in-run auto-repair of lesson bodies.** **Record line — every landed phase** (manual completions included), written into the phase report + ledger notes, verbatim: `retired-token sweep: <tokens> — <N repo hits / M local hits / K exempt>`, with the no-trigger arm `retired-token sweep: n/a` and the memory-disabled arm `retired-token sweep: <tokens> — <N repo hits / local skipped (memory disabled) / K exempt>` (the repo root is still swept whenever it exists). The sweep **never blocks or holds a land** (a detection step that routes findings — ADR 0017-consistent), runs **identically under `--afk`** (Lead-self-adjudicated in both modes, never waits), and is **not** the ADR 0012 phase-close coherence sweep.
