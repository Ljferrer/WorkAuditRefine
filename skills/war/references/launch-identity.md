# Launch identity

Before a new WAR run, plain rerun, or Recovery relaunch, run `node ${CLAUDE_PLUGIN_ROOT}/skills/war/assets/new-run-id.mjs` once in the Lead's shell. Its stdout is the new `runId` (a random UUID). Never derive this ID from the plan/date, copy a prior execution's ID, or generate it inside Workflow. Normal progression to another phase of the same run retains the ID; a same-journal `resumeFromRunId` replay retains both ID and staged bytes. A fresh attempt of a previously launched phase always mints a new ID, even on the same day or another machine.

Persist the same value in assembled `args.runId`, `ledger.json`'s `run_id`, the run manifest's `runId`, and every run-scoped path. Mint it before creating the ledger or staging: `$MAIN/.claude/war/runs/<runId>/` is a new directory for a fresh run, while its phase script basename still carries the readable plan slug and numeric phase. For embedded args, write the new payload into that directory and stage it with `--args`. Never reuse an earlier run's embedded payload or treat `--force` on its old path as a new identity. Reapply only previously approved injected stages to the fresh copy. Preserve previous run directories and manifests for recovery evidence.

Recovery still reuses Git state: keep the same plan slug, numeric phase and task branches; follow `resume-and-recovery.md` for owned-ref continuity and worktree hygiene. Carry the prior phase's manifest record into the new manifest before the existing `attempts[]` archive-and-replace step so the predecessor's telemetry is retained. Git, not these records, remains completion authority.

Every launch requires `runId` and a provisioning-compatible `phase.id`: a nonnegative safe integer or a digit-only string. Explicit task paths waive only path derivation (`planSlug`/`worktreeRoot`); they never waive identity. The engine enforces shape before dispatch. The Lead's producer supplies freshness; deliberately reusing a previous ID for a fresh attempt violates this contract. Legacy date-based IDs remain readable in old records and journal replays, but are never minted for fresh runs.
