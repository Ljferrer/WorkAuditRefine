## Commander's Intent

- **Purpose:** a WAR run never lets a malformed, forged, or contradicted verdict decide a task's fate — every seat finding is normalized before routing, a refiner-reported land, merge-gate or pin-transfer status whose own fields contradict it is refused (D4, D5, D7), every dispatch death is tagged at its site and never reads as a content verdict — and a blocking finding that one seat can specify is fixed in the run instead of escalating the phase.
- **Method:** land the work as a strictly serial ladder over one engine file: card headroom and doc truth first (no engine behavior change), then verdict intake, then ask records, then the land path and enum discipline, then gate segments and the gate-log stamp, then the provision barrier and launch floors, then citations, then re-entry and the ace ladder, then sweep and filing fidelity, then endstate attestation, then the audit-boundary redesign (rebuttal first, then FIX_NEEDED on a surviving fixable blocker; two-sided escalate; seat-conflict ask), then release-slot eligibility by literal, then the cross-cutting dispatch classification, then the release. Its dispatch cost is stated, not hidden: per split task the worst case is one rebuttal seat plus `run.roundLimit` × (one fix worker + the full roster re-audited), against the base's one rebuttal seat and an escalation — `run.maxParallel` bounds how many run at once, never how many run.
