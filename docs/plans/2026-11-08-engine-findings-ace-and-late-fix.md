## New domain terms · Recommended ADRs

- **No-fix sentinel** — a `suggested_fix` text such as "None needed." that names no fix; the floors read it as blank (D1).
- **Reconciled follow-up** — a `demote:absorb-regressed` row that a later ace fixed before land; it moves to `notes` and is never filed (D4).
- **Polish claim** — the first same-wave polish commit to touch a file outside every wave task's `files` owns that file for the wave (D19).
- **Net-zero clash range** — the commits after a task's approved sha that are exactly a clashing polish commit and its forward-revert, with the approved sha's tree (D19).
- Recommended ADR: one for the polish claim rule and the net-zero merge-slot skip. It qualifies ADR 0054's whole-range revert at the merge slot. No ADR for D1–D18.
