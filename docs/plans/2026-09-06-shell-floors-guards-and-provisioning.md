## Context — the gap / problem

The survey's issue cluster describes the shell layer around the engine: the auditor's read-only git guard, the provisioning script and its reuse-hygiene arm, the merge-path floor scripts, the Lead-side lint and preflight scripts, and the campaign ledger. Every cited issue is OPEN at conversion (verified: `gh issue view` per issue at conversion). The defects group into five regions.

**Region A — the auditor git guard has one real bypass and a contract learned by denial.** A command whose only out-of-allowlist byte is a newline is stripped to empty by the `$(...)` at the residue assignment, so `git diff HEAD` followed by a newline and `echo pwned` passes the character check, matches the `diff` arm and is allowed — reproduced through the real JSON hook payload at `ffb3ab6`: exit 0, while the `&&` control exits 2; `git` + newline + `diff` exits 2 on the first-word parse and a newline followed by `&&` exits 2 on the mixed residue, so the bypass is exactly the newline-only shape (verified: issue #1828 (2026-08-27); grill falsifier at `ffb3ab6`). The guard header still says newline "is implicitly denied because it is NOT in the allowlist", and the test file's Group M header lists newline among the chain operators — both false (verified: issue #1830 (2026-08-27); the header NOTE and the `CASE GROUP M` comment at `ffb3ab6`). The deny classifier is binary (chain vs metacharacter), so `>`, `<`, `(`, `)`, `{`, `}` and a lone backslash continuation get the glob/alternation text with a Grep-tool remedy that does not describe the mistake (verified: issue #1829 (2026-08-27); the two-arm `nonchain_residue` branch at `ffb3ab6`). Field measurements: 122 denials in one run, ~2.5 per seat, 64% quote-only; ~66 per plan run in the 2026-09-03 run with backslash continuations the dominant miss (verified: issues #1915 (2026-08-28), #1421 (2026-08-15), #2001 (2026-09-03)).
