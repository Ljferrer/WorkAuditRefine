## New domain terms · Recommended ADRs

**Vacuous run:** a run presented as verification without meaningful coverage of its declared review obligations. Zero findings alone do not establish vacuity: a legitimate clean review may have no findings, and an applicable plan may require analyzed probes only. Distinguish zero dispatches, missing/off-target results, failed confirmations, and evidence too weak to support the advertised claim. This is a scoped operational definition, not a claim that semantic vacuity can be fully decided by code. [assumed: working definition for this experiment — if wrong: refine from observed runs without hiding them]

**Experiment record:** declared baseline → deviation → prediction → test → observation → retain/revise/revert/pending. **Implementation incident:** symptom → hypothesis/verified cause → attempts → decisions → evidence → residuals. Reuse existing vocabulary elsewhere. No ADR creation is required now; recommend a later ADR only if a tested experiment becomes a lasting cross-host contract.
