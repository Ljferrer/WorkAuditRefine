The residue classifier is binary. It strips `&;|` and newline, and any byte left takes the metacharacter message, which talks about globs and the Grep tool (verified: `nonchain_residue` in `hooks/validate-auditor-git.sh` at 35aa4144). A redirect, a brace or a backslash gets a remedy that does not fit, and loses the "one bare command" remedy, which now lives only on the chain branch (verified: issue #1829 (2026-08-27)). The `git grep` rule admits one shape: `-F` plus exactly one `-e <token>`, optional `-n/-i/-l/-w/-c`, one revision and `-- <pathspec>` (verified: `grep_deny` in `hooks/validate-auditor-git.sh` at 35aa4144). It is the largest remaining denial class: 38 of 58 in one recurrence (verified: issue #2627 (2026-11-05), recurrence comment). The operator ruled that "not a git command" stays on purpose and that #1915 carries the live count (verified: issue #2556 (2026-10-31)). The operator also ruled that #2374 closes only when search-class denials stop in the most recent phases (verified: issue #2374 (2026-10-06), operator comment 2026-10-31).

The hook's grep deny string is canonical for two extraction tests. The D6 tests in `workflow-template.engine-1.test.mjs` read the `grep_deny` string and the branch deny string from the hook, and assert every listed flag onto the auditor card and the dispatched `auditPrompt()`. Each test locates its string by the opening fragment — `deny "git grep admits one form only:` and `deny "git branch admits read forms only:` — so those two fragments are anchors, not prose. The grep test reads the first `optional <list> ` capture in the string, requires that slash list to be set-equal to the hook's `n|i|l|w|c` cluster arm (the first lowercase `x|y|z)` arm in the file), and each token to be a lowercase short flag. The branch test requires exactly two parenthesized flag groups (verified: the two `D6 —` tests in `skills/war/assets/workflow-template.engine-1.test.mjs` at 35aa4144). So a hook change that puts a new flag into those lists, rewords an opening fragment, or puts a new `optional` clause before the `-n/-i/-l/-w/-c` one reds the engine suite until the mirrors follow. The hook's own COUPLING comment above `grep_deny` names only group P of the hook test, not the engine test (verified: the `# COUPLING:` comment above `grep_deny` at 35aa4144). `skills/war/references/auditor-teach.md` restates the grammar as "exactly one `-e <token>` … every regex selector deny" in a dated note, and the engine test reads that file only for retired-claim absence scans (verified: the D21 note in `auditor-teach.md` and the `auditorTeachMd` scans in `workflow-template.engine-1.test.mjs` at 35aa4144).

"The Grep tool first" sits near the end of that long line, not at the top of the prompt (verified: same line at 35aa4144). The 18 non-git calls in #1915 came from `execution-evidence` gate-audit seats that read the refinery `.war` folder with `ls`, `find`, `cd` and `tail` (verified: issue #1915 (2026-08-28)). **B. Workers write files through Bash, and a host denial splits a phase.** The worker card has no rule on which tool changes a file (verified: `agents/war-worker.md` at 35aa4144). The scope and lint hooks match only `Write|Edit|NotebookEdit`, and the Bash write hook only warns and always exits 0 (verified: `hooks/hooks.json` matchers and the header of `hooks/warn-bash-write-scope.sh` at 35aa4144).
