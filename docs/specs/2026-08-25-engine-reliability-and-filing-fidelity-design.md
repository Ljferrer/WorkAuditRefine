# Engine reliability and filing fidelity — pacing knob, budget mechanization, and the workflow-template hardening ladder

Issues addressed (all claimed by this spec): #1552, #1586, #1671, #1430, #1666, #1480, #1679, #1680, #1681, #1672, #1476, #1456, #1560, #1561, #1562, #1597, #1592, #1589, #1575, #1574, #1571, #1659, #1660, #1577, #1435, #1421, #1688.

## 1. Context — the gap / problem

Two operator-directed enhancements lead this group, and behind them sits a backlog of engine-reliability and filing-fidelity defects that almost all live in one file — `skills/war/assets/workflow-template.js` — and therefore cannot be parallelized against each other.

**Enhancement 1 — no fan-out throttle.** WAR's Workflow fans out workers and auditor rosters via script-level `parallel()` calls; there is no `run.maxParallel` anywhere in the tree, and the harness concurrency cap (`min(16, CPUs − 2)`) has no override — the upstream request is open with no ETA (verified: issue #1552 (2026-08-25)). The fan-out sites are `parallel(roster.map(...))` (seat roster, plus its dropped-seat retry), the per-wave task fan-out `parallel(wave.map(...))`, and the post-merge gate-audit `parallel(mergedTasksForGateAudit.map(...))` (verified: `skills/war/assets/workflow-template.js` `parallel()` call sites at HEAD (2026-08-25)). On rate-limited accounts the concentrated spend exhausts the rolling 5-hour window even when total tokens are fine (verified: issue #1552 (2026-08-25)).

**Enhancement 2 — budget maintenance is half-mechanized.** The advisory headroom tier in `prompt-surface-budgets.test.mjs` has landed (two-tier, formula-derived ×1.25 headroom) (verified: issue #1586 reader summary (2026-08-25)); the remaining scope is (a) the operator-gated re-baseline pass (preflight → plan → one gate → execute → report, mirroring `/lessons-learned tighten`) and (b) a merge-time citation floor: a diff touching a ceiling constant must carry a `Budget-Raise: ADR-0042 <surface> +<bytes>` commit trailer or route to the no-test-style fix-worker path (verified: issue #1586 (2026-08-25)). The motivating incident was a worker re-baselining a ceiling +9,216 B to fund +232 B, caught only because the raise carried no citation (verified: issue #1586 (2026-08-25)).

**Launch preflight / args provenance.** A missing `plan.file` silently no-opped an entire phase — the pt throw was swallowed by the wave-thunk catch (verified: issue #1430 (2026-08-25)); fix 1 (plan.file entry class + `<unset>` defaults) shipped, but `task.planSlice` is still a bare interpolation at both worker prompt sites, per-task entry validation is absent, and the vacuous land-barrier endstate (zero tasks ran ⇒ still green) is unfixed — a 2026-08-25 recurrence with `planSlice` proves it (verified: issue #1430 / issue #1671 (2026-08-25); bare `${task.planSlice}` confirmed at both worker prompt builds in `workflow-template.js` at HEAD (2026-08-25)). #1671 asks for a Lead-side `assert-args-complete.mjs` floor (exit 0/1/2) deriving required pt fields from the template source, wired into `skills/war/SKILL.md` launch, plus a default-deny census test of bare interpolations (verified: issue #1671 (2026-08-25)). The #1413 own-token provenance floor is mis-calibrated both directions — substring `includes()` over `JSON.stringify` per surface, foreign-id check with no predecessor-citation exemption, no word-boundary/stoplist (verified: issue #1480 (2026-08-25); the `ownTokens` / `foreignIds` floor confirmed in `workflow-template.js` at HEAD (2026-08-25)) — and it false-refuses plan-agnostic backstops carrying Lead-stamped `planFile` provenance (verified: issue #1666 signal 1 (2026-08-25)).

**Endstate-check artifact fidelity.** Three mined defects in the land-barrier endstate-check dispatch's `.cmd` generation/capture: (1) a correctly single-quoted plan `check:` literal containing a `${...}` run gets re-rendered double-quoted — bash dies "bad substitution" and the whole `&&` chain never runs (verified: issue #1679 (2026-08-25)); (2) an embedded backtick inside a `grep -qF` argument is treated as the closing fence delimiter, writing a truncated `.cmd` that dies with an unexpected-EOF parse error (verified: issue #1680 (2026-08-25)); (3) the dispatch tees one command per condition row — a two-command check's second half is never captured, and pipeline/compound grep checks systemically come back exit 0 with empty stdout across three phases, so gate-audit seats hand-re-ground on the pinned blob, an unrecorded step (verified: issue #1681 (2026-08-25)). Per the #1395 amendment these environmentally-red artifacts attest unverified (never unmet), so phases proceed with permanently machine-unprovable conditions (verified: issue #1679 (2026-08-25)).

**Filing/consolidation fidelity.** The follow-up consolidation collapse keys on file+line only: same-seat same-file rows within the line window also collapse, and every merged-away row survives only as a `seats[]` ref — title and rationale are dropped from `minorsFiled`, the handoff, and the filing prompt (verified: issues #1571, #1575 (2026-08-25); the collapse appending only `seatRef(f)` confirmed in `workflow-template.js` at HEAD (2026-08-25)). `seatRef` is `f.seat ?? 'task '+f.task` — seat-only, so a cross-task collapse loses corroborating-task attribution (verified: issue #1574 (2026-08-25); construct confirmed at HEAD (2026-08-25)). The filing-prompt row renderer still calls `m.seats.join` behind a truthiness (not `Array.isArray`) gate, so an auditor-supplied string `seats` kills the whole filing batch (verified: issues #1592, #1597 (2026-08-25); the `m.seats && m.seats.length ? m.seats.join(...)` render confirmed at HEAD (2026-08-25)); #1597 additionally wants `schemas.md`'s `minorsFiled` collapse qualified as conditional on handoff-emitting decisions (verified: issue #1597 (2026-08-25)). A guard comment claims the collapse block "runs outside any try" — literally false, it is inside the top-level try (verified: issue #1589 (2026-08-25)). The Evidence-artifacts extraction clause mis-reads a `:rebut` seat suffix as the lens (verified: issue #1659 (2026-08-25)), and `auditEvidenceOf`'s sha fallback renders "unrecorded" for every `requiresTest:false` task (verified: issue #1660 (2026-08-25)). ADR 0013 Decision 4 still describes 1:1 finding→issue filing; the landed behavior is N:1 clustered filing with dedup-as-corroboration-comment (verified: issue #1577 (2026-08-25)).

**Land-path and phase-close robustness.** Three more signals from a live run: the land dispatch dies when the gate outruns the ~2 min tool timeout (needs a segmented/incomplete status, not a death), and a `held:land-failed` phase leaves the follow-up filing dispatch unrun (verified: issue #1666 signals 2–3 (2026-08-25)). When any phase-close polish dispatch dies, the fail-open coherence sweep demotes the entire absorb queue to a flat untriaged follow-up dump with no drain-cause metadata; `provisionStep` dispatches via bare `agent(...)`, outside the `dispatchAgent` soft env-died classification (verified: issue #1672 (2026-08-25); `provisionStep` and `dispatchAgent` both confirmed as distinct constructs in `workflow-template.js` at HEAD (2026-08-25)).

**aceBisect robustness.** The Ace-Subset trailer value is `taskId+':'+sorted-files`, so a child subset's trailer is a strict prefix of its parent's and the prompt mandates neither exact-value equality nor a blank-line-separated final trailer block (verified: issue #1560 (2026-08-25)); culprit attribution is exact `culpritFiles.has(f.file)` string equality, so path-form drift silently forgoes culprit-first (verified: issue #1561 (2026-08-25); construct confirmed at HEAD (2026-08-25)); subset commits and merge-floor retries draw one undifferentiated `fixRounds` pool, so the ladder can starve the floor-retry loop — a decision-shaped item (verified: issue #1562 (2026-08-25)).

**File-disjoint peripheral hardening.** (a) `provision-worktrees.sh`'s reuse-hygiene arm has four fail-open gaps: no `--untracked-files=all` porcelain read, deliberate git-rm ambiguity, SIGPIPE misclassification, and `cmd_ensure_refinery_worktree` carries no hygiene arm (verified: issue #1476 (2026-08-25)). (b) `campaign-ledger.mjs` `case 'record'` copies `status`/`branch`/`sha`/`stopPoint` via `hasOwnProperty` with no typeof guard, while `pr`/`redteamRounds` carry the typeof+regex refusal — a bare flag stamps boolean `true` into the ledger (verified: issue #1456 (2026-08-25); the unguarded copy loop confirmed at HEAD (2026-08-25)). (c) `validate-auditor-git.sh` emits one unconditional metacharacter-rule deny clause for every out-of-allowlist byte, over-attributing chain-operator denials (verified: issue #1435 (2026-08-25); the single `residue` deny confirmed at HEAD (2026-08-25)). (d) #1421 carries three separable items: the `skills/war/SKILL.md` test-floor prose claims a single-star token covers root and nested files without stating the star must be leading (verified: issue #1421 (2026-08-25); the claim present in SKILL.md step 3 at HEAD (2026-08-25)); 186 auditor-git-guard denials of composed/`git grep` commands in one run; and `assert-issues-filed.sh --close-epic` half-applies on older `gh` lacking `--reason` (verified: issue #1421 (2026-08-25); labels-first-then-`gh issue close --reason` order confirmed at HEAD (2026-08-25)). (e) `assert-guard-specificity-in-diff.sh`'s `extract_msg` records a die guard's whole quoted literal, so a message with an unexpandable `$var` tail can never be honestly covered — a structural floor ceiling with six recorded recurrences (verified: issue #1688 (2026-08-25)).

## 2. Pivotal constraints

- `run.maxParallel` absent/`null` ⇒ byte-identical fan-out to today; batching changes only *when* thunks start, never how results are collected — the one-collected-result-per-dispatched-task wave-loop invariant (#742) holds (verified: issue #1552 (2026-08-25)).
- Ceiling HARD semantics at gate time unchanged; the citation floor makes uncited raises impossible, sizing stays audit-side (verified: issue #1586 (2026-08-25)).
- Enum discipline: no new members of `HARD_ESCALATION_REASONS` / `KNOWN_LAND_DECISIONS` without updating both hand-mirrored copies and the drift-guard row together; `held:workflow-error` never enters `HARD_ESCALATION_REASONS` (ADR 0005). Floor scripts exit 0/1/2 with 2 = git error never collapsing into the floor status.
- Standing/dispatched prompt split: any auditor/refiner behavior change updates `agents/*.md` and the `workflow-template.js` prompt build in the same commit.
- `workflow-template.js` is under active edit by the in-flight ask-disposition campaign — this spec's template phases sequence after it lands (verified: issue #1430 reader summary (2026-08-25)).
- Guard changes in #1435/#1421(b) are message-only: allowlist, exit codes, and routing byte-unchanged (verified: issue #1435 (2026-08-25)).

## 4. Mechanics

- **Batching helper (P1):** a `batched(thunks, n)` in `workflow-template.js` awaiting slices serially; threaded `run.maxParallel` exactly like `roundLimit` with the args-contract header comment updated in the same commit (verified: issue #1552 (2026-08-25)). `design.md`'s concurrency line names the knob.
- **Citation floor (P2):** new `hooks/`-style script scanning the merge diff for ceiling-constant touches in `prompt-surface-budgets.test.mjs`; missing `Budget-Raise:` trailer ⇒ exit 1 (the named route), git error ⇒ exit 2; refiner wiring mirrors the existing merge-path floors, with `agents/war-refiner.md` and the dispatched refiner prompt updated together. The re-baseline pass lands as a doctrine/reference surface (the `/lessons-learned tighten` mirror), operator-invoked, never mid-task [assumed: reference-doc + skill-prose lane rather than a new skill directory — if wrong: the pass becomes a new skill entry point at plan time, same content].
- **Preflight floor (P3):** `assert-args-complete.mjs` reads the template source and extracts fallback-free `${args...}`/task-field interpolations mechanically [assumed: regex-level extraction over the template file is sufficient (no AST) — if wrong: the census test still pins the field set and the floor consumes the pinned list instead]; SKILL.md launch step invokes it before dispatch. Engine belt per D5; provenance recalibration per D6 in the same entry region.
- **Endstate transport (P4):** the dispatch's per-row `cmd-file:` build (`endstate-<phaseId>-<n>.cmd`) writes the check literal via a transport that never re-quotes (e.g. the prompt instructs byte-verbatim file write from a fenced block whose fence length exceeds any inner run) [assumed: prompt-side transport fix, since the Workflow sandbox builds prompts, not files — if wrong: a provision-step writer script owns the `.cmd` bytes and the prompt only names paths].
- **Collapse/filing (P5):** all inside the follow-up consolidation + filing-prompt region; `schemas.md` and ADR 0013 ride as file-disjoint sibling tasks.
- **Land/phase-close (P6):** the segmented land status must not widen any shared enum without both mirrored copies + drift guard (Pivotal constraints); `held:land-failed` filing handoff may reuse the existing fail-open filing dispatch, re-pointed.
- **aceBisect (P7):** trailer value gains a terminator (or the preflight scan mandates exact-value trailer equality); `culpritFiles` comparison normalizes `./`-prefix/path form.
- **Peripheral floors (P8):** each per D13, independent files, each with its paired `.test.sh`/`.test.mjs` updates.

## 10. Validation criteria

- WHEN `run.maxParallel` is absent THE per-wave fan-out SHALL be byte-identical to today's `parallel()` behavior · check: `node --test skills/war/assets/workflow-template.test.mjs` (a default-path census row asserting no batching branch taken; the suite must print its pass count, never bare exit).
- WHEN `run.maxParallel: N` is set THE wave SHALL dispatch at most N task thunks concurrently, group k+1 starting only after group k settles · check: a deterministic batching-helper unit test in `workflow-template.test.mjs`.
- WHEN a merge diff touches a ceiling constant in `prompt-surface-budgets.test.mjs` without a `Budget-Raise:` trailer THE floor SHALL exit 1 with the named route, and exit 2 on git error · check: the floor's own `.test.sh` (fail-closed classification census row included).
- WHEN a launch omits any fallback-free pt args field THE `assert-args-complete.mjs` floor SHALL exit 1 naming the field before any dispatch · check: `node --test` on its test file. (The census grep of bare interpolations is a floor: after it, hand-scan `workflow-template.js`'s prompt-build regions for interpolations the pattern misses and list each as a survey-derived correction.)
- WHEN a plan `check:` literal contains `${...}` runs, embedded backticks, or two mandatory commands THE executed `.cmd` artifact SHALL reproduce the literal byte-verbatim, run every command, and tee full stdout — or fail loudly · check: fixture rows in `workflow-template.test.mjs` covering all three shapes.
- WHEN two distinct findings collapse THE filing prompt, issue body, handoff `followUps`, and log SHALL each carry the merged-away row's title and rationale, and `seats[]` SHALL carry seat+task attribution · check: consolidation fixture assertions in `workflow-template.test.mjs`.
- WHEN an auditor supplies a string `seats` on a non-collapsing row THE filing batch SHALL render that row without throwing · check: an `Array.isArray` fixture row.
- WHEN a phase-close polish dispatch dies THE demoted findings SHALL each carry a drain-cause stamp (or the dispatch SHALL classify env-died soft) · check: a `provisionStep`/polish-path classification test.
- WHEN `campaign-ledger record` receives a bare `--status`/`--branch`/`--sha`/`--stopPoint` THE CLI SHALL refuse loudly before any `record()` call, ledger byte-identical · check: `node --test skills/war-campaign/assets/campaign-ledger.test.mjs`.
- WHEN an auditor command is denied for a chain operator vs. a glob metacharacter THE deny message SHALL name the actual rule class, decision and exit code byte-unchanged · check: `bash hooks/validate-auditor-git.test.sh`.
- WHEN `gh issue close --reason` is unsupported THE `--close-epic` path SHALL still close the epic (degraded, loud) · check: a stubbed-gh case in its `.test.sh`.
- WHEN a new die guard's message ends in a `$var` interpolation THE guard-specificity floor SHALL accept an honest distinguishing-prefix stderr assertion as covered · check: `bash skills/war/assets/assert-guard-specificity-in-diff.test.sh` [assumed: the test file sits beside the script under that name — if wrong: the plan names the real suite at decompose].
- WHEN zero tasks ran in a phase THE land-barrier endstate SHALL never attest green · check: a vacuous-endstate fixture in `workflow-template.test.mjs`.
