## 2. Pivotal constraints

- **Base.** This spec's plan builds on master after PR #2065 lands. Every construct above was verified at master 59e33f3; #2089's instance files (`gate-audit-checklist.md`, `gate-failure-classification.md`) exist only on the PR #2065 branch, so the census in Phase 3 must be authored against the post-#2065 `skills/war/references/` listing (verified: issue #2089 (2026-09-06) on the PR #2065 branch).
- **Living-ADR law lands before any ADR edit in this plan.** ADR 0044 (#1848) and the projections ADR (#1880) are written under the new law — in place, no dated amendment heading. Phase edge, not deps.
- **Policy vs. record.** The new law covers policy files: `docs/adr/`, `skills/*/references/`, `CONTEXT.md`, `README.md`. Record surfaces stay immutable: `docs/plans/`, `docs/specs/`, `docs/red-team/`, `docs/roadmaps/`, `CHANGELOG.md` bodies, `docs/learnings/` provenance. So #2084 is fixed on the lint side (advisory row), never by editing the grandfathered plan; #1399 is fixed under the archive's relaxed freeze by extending the existing correction section, never by rewriting the frontmatter or provenance.
- **One owning task per shared suite per phase.** `skill-doc-contracts.test.mjs`, `reference-link-integrity.test.mjs`, `doc-cli-consistency.test.mjs`, `prompt-surface-budgets.test.mjs`, `plan-literal-lint.mjs` (+ test), `version-slots.test.mjs` — each has exactly one owning task in any phase that touches it (code-boundary rule 1).
- **Mirror rule.** A standing-card sentence that the dispatched prompt in `workflow-template.js` mirrors is never reworded here. The Vale pass on `agents/*.md` treats every drift-guard-pinned or dispatched-prompt-mirrored literal as byte-frozen; a finding that can only be resolved by rewording such a literal is listed as a survey-derived follow-up for the engine sibling, not fixed.
- **Byte-identical pointer line.** The `docs/learnings/` pointer at the top of `CLAUDE.md` is never touched.
- **Budgets ratchet down, never up.** `skills/war/SKILL.md` (73,728 B hard), `CONTEXT.md` (126,976 B hard), `agents/*.md`, `skills/lessons-learned/SKILL.md` and `CLAUDE.md` carry `FILE_BUDGETS` rows (verified: `skills/war/assets/prompt-surface-budgets.test.mjs` `FILE_BUDGETS` at 59e33f3). Every phase that grows one of these measures with `wc -c` after the edit. A raise is out of scope for every phase here.
- **New guards are both-ways proven.** Each new row or fragment records a scratch-flip proof (extraction non-empty; a scratch reword reds).
- **Grep is a floor, not a ceiling** — every sweep step below carries the hand-scan note.
- **Release bump is its own trailing phase** over the four slots, "next free patch above the live base", never a literal.
- **Zero new runtime dependencies.** #1880 lands as repo-native mermaid/HTML projections plus doctrine; the BuilderIO skills are never a dependency.

## 6. New domain terms (CONTEXT.md)

- **Living ADR** — an ADR body states current law and is rewritten in place; git is its archive. _Avoid:_ a dated amendment heading appended below a body that no longer holds.
- **Sha-pinned citation** — `docs/adr/<file> @ <sha>`: the ADR as it stood at that commit. A bare citation means current law.
- **Policy surface / Record surface** — policy is rewritten in place (ADRs, references, glossaries, README); a record is immutable once landed (plans, specs, red-team reports, roadmaps, CHANGELOG bodies, learnings provenance).
- **Projection (visual)** — a generated one-way render of a merged plan or landed diff. _Avoid:_ editing the projection; feedback goes to the `.md`.
- **Partial-source read** — an evidence object cited as read but consumed only in projection (body without comments, `| head`-truncated). The fourth leak shape.
