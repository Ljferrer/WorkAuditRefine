## 1. Context — the gap / problem

Sixty-four open issues describe one file family: the per-phase Workflow engine `skills/war/assets/workflow-template.js`, its test `skills/war/assets/workflow-template.test.mjs`, the canonical enum module `skills/war/assets/land-decision.mjs`, and the two agent cards whose dispatched prompts the engine string-builds (`agents/war-auditor.md`, `agents/war-refiner.md`). Almost every fix lands in the engine file, so the work cannot be parallelized inside a phase; it can only be laddered. ## 2. Pivotal constraints

- **Base.** Every phase in this spec builds on `master` after PR #2065 lands. Issues #2034, #2051, #2053, #2058, #2059, #2060, #2068 name constructs that exist only on that branch (verified: PR #2065 state OPEN, base `master`, at survey time); the `DEMOTE_REASONS` enum, `absorbRounds`, `aceLabel`, `pendingAbsorbs` and `floorSkipped` are all branch-only (verified: `grep -c DEMOTE_REASONS land-decision.mjs` 0 at 59e33f3, present at 0741387). The plan interview re-verifies every §1 line anchor against the merged tip before decompose.
- **One owner per shared file per phase.** `workflow-template.js`, `workflow-template.test.mjs`, `land-decision.mjs`, each agent card, `schemas.md`, `CONTEXT.md`, `skills/war/SKILL.md` each have exactly one owning task in any phase. The test task carries `deps` on the engine task (guard-split deps edge, `/war-strategy` §3 rule 7).
- **Standing/dispatched split.** A task that edits a dispatched auditor or refiner prompt in `workflow-template.js` also owns the matching `agents/*.md` card in the same commit. Every such pair gets a both-surfaces registry row in `workflow-template.test.mjs` (the D3 BOTH-SURFACES REGISTRY, no-slack `REGISTRY.length` floor bumped in the same task as the row) (verified: issue #2005 (2026-09-03) names the registry pattern).
- **Enum discipline.** `HARD_ESCALATION_REASONS` and `KNOWN_LAND_DECISIONS` change in `land-decision.mjs`, the inline mirror and the drift-guard row together (ADR 0005 rule: `held:workflow-error` never enters the hard set). `MERGE_RESULT.status` is never widened — `incomplete` and `budget-uncited` ride as in-band fields (the `land_segment`/`floor_route` precedent) (verified: `floor_route` comment `NO status enum value` at 59e33f3).
- **Budgets.** Card growth is funded under the ceiling or by an ADR 0042 eviction; `prompt-surface-budgets.test.mjs` ceilings ratchet down after an eviction and are never raised by a worker (ADR 0048). New `references/` destinations must join `reference-link-integrity.test.mjs`'s `QUALIFIED_HEADERS` in the same task (lesson `adr-0042-eviction-destination-creation-does-not-auto-register-in-qualified-headers`).
- **Floor semantics.** Exit 0/1/2 for scripts; a fail-closed engine arm refuses with a log line, never a silent `continue`.
- **Grep is a floor** for every site census this spec orders (bare `dispatch(` sites, must-reach-every-seat directives, gate-audit-family prompt builds, old-prose absence checks): after the grep, hand-scan the target file's same-scope tests and comments and list each straggler as a survey-derived correction.
